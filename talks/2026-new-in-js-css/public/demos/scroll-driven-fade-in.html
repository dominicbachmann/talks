Scroll-Driven Progress Bar

A fixed bar at the top that fills as you scroll the page. Uses animation-timeline: scroll(root) with a keyframe that goes from scaleX(0) to scaleX(1).

Fade-In on Scroll

Elements fade and slide in as they enter the viewport. Uses animation-timeline: view() — a CSS-native replacement for IntersectionObserver + class toggle patterns.

CSS

Parallax Backgrounds

Background layers move at different rates than foreground content. Each layer uses scroll() with different keyframe ranges to create depth.

CSS

Shrinking Sticky Headers

Headers that reduce their padding and font size as the user scrolls down. Previously required reading scrollTop and setting inline styles on every scroll event.

Compositor Thread Performance

Scroll-driven animations run on the compositor thread, not the main thread. This means they don't compete with JavaScript execution and are immune to main-thread jank.

Performance

Reversibility for Free

When you scroll back up, the animations reverse automatically. No extra code for scroll-direction detection — the browser handles it because animation progress is tied to position, not events.

CSS

animation-range Control

The animation-range property lets you specify exactly when the animation starts and ends relative to the element's visibility — entry, exit, contain, or cover phases.

CSS

Progressive Enhancement

In browsers that don't support scroll-driven animations, the keyframes are simply ignored. Elements appear normally with no animation — no broken layout, no errors.
