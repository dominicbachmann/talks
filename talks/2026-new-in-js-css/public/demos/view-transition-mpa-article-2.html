Scroll-Driven Animations Without JavaScript

March 5, 2026

Scroll-linked effects used to mean attaching a listener to the scroll event or setting up an IntersectionObserver, then manually updating styles frame by frame. Performance was fragile, and the code was always more complex than the visual effect warranted.

The Scroll Timeline API lets you bind any CSS animation to scroll progress or an element's position in the viewport. A progress bar that fills as you scroll, a parallax hero, or a fade-in on reveal — all declarative, all running on the compositor thread.

The key primitives are scroll-timeline (tracks a scroller's offset) and view-timeline (tracks an element's intersection with its scrollport). Pair either with animation-timeline to drive any keyframe sequence.
