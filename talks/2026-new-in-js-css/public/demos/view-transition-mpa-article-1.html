CSS @scope: Native Style Isolation

March 12, 2026

For years, CSS scoping required workarounds: BEM naming conventions, CSS Modules hashing class names at build time, or Shadow DOM's hard encapsulation boundary. Each came with trade-offs — naming discipline, toolchain coupling, or limited styling flexibility.

The @scope rule changes this. You define a scoping root and an optional lower boundary, and the browser contains your styles to that subtree. No build step, no runtime overhead, and it works with the cascade you already know.

Combined with @layer for ordering and container queries for responsive components, @scope rounds out the set of primitives that make CSS-in-JS tooling optional for many projects.
