Parallax with scroll()

The colored shapes behind this text each have a different @keyframes range, tied to animation-timeline: scroll(). They translate at different speeds as you scroll — creating depth with zero JavaScript.

animation-timeline: scroll()

Reveal with view()

Each text section uses animation-timeline: view() to fade and slide in as it enters the scrollport. The animation-range: entry property controls exactly when the animation plays.

animation-timeline: view()

Two Timelines, One Page

The parallax shapes use scroll() — driven by the container's overall scroll position. The text sections use view() — driven by each element's individual visibility. Both run simultaneously on the compositor thread.
