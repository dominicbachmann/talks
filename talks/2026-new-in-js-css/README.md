# What's New in JavaScript & CSS

A talk covering recently landed APIs, patterns, and features in JavaScript and CSS — presented at [JavaScript Luzern](https://www.meetup.com/javascript-luzern/) by Dominic Bachmann.

## Topics

1. **Temporal API** — modern date/time handling
2. **Trusted Types** — DOM XSS prevention via CSP
3. **View Transitions** — SPA and MPA page transition animations
4. **Anchor Positioning** — CSS-based positioning relative to anchor elements
5. **@starting-style** — entry animations for dialogs, popovers, and more
6. **Popover API** — native, accessible popovers without JS
7. **Native Dialog** — `<dialog>` for modals and confirmations
8. **Invoker Commands** — declarative button-to-target interactions
9. **Logical Properties** — writing-direction-aware layout properties
10. **Scroll-Driven Animations** — scroll-linked animations without JS

## Tech Stack

- [Reveal.js](https://revealjs.com/) via [@revealjs/react](https://www.npmjs.com/package/@revealjs/react)
- React 19, TypeScript, Vite 8
- Live HTML demos in `public/demos/`
